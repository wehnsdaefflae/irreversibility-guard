# What is in this directory, and what is deliberately NOT

The external evaluation (see `../../RESULTS.md`) is scored on third-party corpora. What is
checked in here is **only what re-deriving the published numbers requires**:

| file | what it is |
|---|---|
| `agentharm-index.jsonl` | for each AgentHarm prompt: its id, name, config, split and `target_functions` — the tool calls the benchmark says that prompt is meant to drive. **416 rows.** |
| `agentharm-labels.json` | the per-function `destructive` / `outward` labels, produced by a model shown no guard source, no manifest and no mention of a guard. **85 functions.** |
| `benign-traffic.jsonl` | 150 legitimate agent calls generated by an independent model over a real tool surface. |
| `prompt-injections.jsonl` | `deepset/prompt-injections`, 662 rows, CC-BY-4.0 — kept because it is reported as a **negative result**. |
| `translated.jsonl` | that corpus mapped to proposed tool calls by an independent model. |

**The AgentHarm prompt texts are deliberately not redistributed here.** They are 208
prompts written to drive an agent into harmful tool use; this repository has no need of
them (the evaluation consumes `target_functions`, not the prose) and republishing a harm
corpus is not this project's business. Fetch them from the source if you want them:

```sh
# ai-safety-institute/AgentHarm, configs: harmful, harmless_benign; splits: test_public, validation
curl -s "https://datasets-server.huggingface.co/rows?dataset=ai-safety-institute%2FAgentHarm&config=harmful&split=test_public&offset=0&length=100"
```

Nothing in the published numbers depends on having them: the ids here line up with the
benchmark's own, so any claim in `RESULTS.md` can be checked against the source.
